# Security Policy

Please report potential vulnerabilities in **the toolkit itself** privately through GitHub's **Report a vulnerability** feature when enabled, rather than filing a public issue containing exploit details, secrets or customer information.

For vulnerabilities found **using** the toolkit, follow the affected project's own authorized reporting policy and coordinated-disclosure timeline. This repository is not a disclosure inbox for third-party application vulnerabilities.

Do not publicly publish unreleased proofs of concept, secrets, or unpatched third-party findings without authorization.
